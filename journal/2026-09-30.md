# 2026/09/30｜UE 材质练习、LogSigmoid 算子优化

UE 材质练习围绕按高度变化的石化效果展开。读取世界坐标的 Z 分量，减去控制分界位置的高度参数，再经过 SmoothStep 生成平滑遮罩，用它混合颜色和粗糙度。加入噪声后，石化边界不再完全平直。当天还没有制作发光边缘，主要是在已有节点上继续确认每一步的含义。

重点讨论了两种不同的 Mask。Component Mask 只是从向量中取出指定分量：输入世界坐标时，第三个分量是 Z，所以可以拿来表示高度，但这个节点本身并不是“筛选高度”的工具。用于材质混合的黑白遮罩，则用 0 到 1 的值控制效果比例。世界坐标节点已经有独立 Z 输出时，可以直接使用，不必额外接 Component Mask。

SmoothStep 和 Lerp 也结合当前效果重新解释。前者把指定区间内的数值变成平滑的过渡，后者根据这个结果混合两组属性。同一个遮罩既能控制颜色，也能控制粗糙度，不需要为每种属性重新做一套高度判断。RGB、XYZ 和材质参数虽然有不同含义，底层都可以是由几个数构成的数据，具体用途取决于它们接到哪里。当天主要是在节点练习中认识这些关系，还没有独立编写完整的 HLSL 材质。

随后补充了 UV、法线烘焙和 SP 烘焙贴图的基础。UV 决定从贴图哪里读取数据，法线参与光照计算；法线贴图能表现表面细节，却不会改变模型轮廓。SP 一次烘焙得到多张图，是因为法线、遮蔽、曲率、位置等信息各有用途，其中一些用于辅助生成磨损和污渍，不一定全部直接导入引擎。还以汽车车漆为例，讨论了粗糙度、微表面法线、清漆层等因素怎样共同影响质感。这部分是概念学习，尚未完成对应材质作品。

消防栓也准备重做。原来的圆柱拼接、布尔和手动合并让接口附近越来越难修，对照参考图，根部还缺少自然的圆润过渡。平滑着色只能改变光照表现，不能把硬交界变成真正的圆角。最后决定尝试从一个圆柱出发，用挤压和缩放建立连续结构，先完成主体，再规划侧接口。当天确定了新做法，没有完成重做后的模型。

算子比赛方面，开始处理 CCPC 长春站的 Ascend C LogSigmoid。AI 读取模板、编写实现并执行 CPU 数值检查，用户负责线上提交和返回评测结果。本机没有可用的 NPU 运行条件，因此本地数值检查不能代替设备编译、正确性和性能验证。

首版获得 27.93 分，性能表现不理想。后续修改减少了较重的计算链，新候选通过十个测试点，性能有所改善。之后没有继续急着微调提交，而是要求先复盘已有实现，重新检查并行策略、指令成本和实验安排。代码主要由 AI 完成，用户参与评测反馈和优化方向的审查，不能把这次结果写成独立掌握了算子开发。

另外，CSA48 猪猪榜增加了随机头像功能。首版素材不符合预期，查看预览后改用安卓猪猪表情，撤回旧 PR 并提交新版，等待维护者合并。功能检查之外，素材和视觉效果也经过了重新确认。
