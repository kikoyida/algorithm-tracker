# 2026/10/07｜UV 展开、挤出操作与 PBR 资产计划

今天继续补 Blender 到 Substance Painter、再到 UE 的资产流程。水下场景先留下了阶段版本，接下来希望做一个能放进作品集的模型，而不是只完成外形、套上材质就结束。晚上主要在弄清 UV 是什么，以及一件资产从建模到最终展示，中间还有哪些环节需要自己走一遍。

## 展 UV 到底在做什么

刚开始看 Mark Seam、Unwrap、调整 UV Islands 这些名字，感觉流程一下子变得很复杂。讨论后先把它们放回一个具体画面：模型是立体的，贴图是平面的，UV 负责建立模型表面与二维图片之间的对应关系。展开时把表面分成可以摊开的区域，软件才知道图片上的颜色、划痕或标签应该落在模型哪里。

纸盒和圆柱的例子比较容易想象。纸盒沿一些边剪开，可以摊成相连的几个平面；圆柱则可以把顶底与侧面分开，侧面再沿长度方向切开，展开后成为一块长方形。每块展开的区域就是一个 UV Island。切缝、展开和调整岛的位置不是三个互不相干的操作，而是在决定表面如何拆分，以及这些区域怎样放进纹理空间。

这也让 UV 与前几天的材质操作有了联系。之前在 UE 中用世界位置、程序化噪声做效果，并不总是需要手动展开 UV；但想在 SP 中绘制、烘焙，或准确放置文字和污渍，就需要认真处理模型与纹理的对应关系。

当天还没有完成一套手动展开练习。AI 给出的入门办法是先用 Smart UV Project 体验自动展开，再逐步学习手动切缝、检查拉伸和调整岛。自动展开可以帮助理解流程，但不能把它与一份经过检查、适合最终资产使用的 UV 等同起来。

## 下一件资产的范围

晚上明确了新练习的要求：希望做一个能放进作品集、也能用于完整场景的原创资产，可以参考教程，但总投入尽量控制在十天以内。重点不是机械结构越复杂越好，而是能够从头到尾完成一次 PBR 资产制作。

讨论中的流程是：参考与灰模、高模与低模、低模 UV、烘焙、SP 材质，最后导入 UE 做灯光与展示。高模负责较细的倒角和表面结构，低模保留需要的轮廓，再通过烘焙把部分细节转移到贴图上。材质部分则需要分别处理基础颜色、粗糙度、金属度和法线，不是给整个模型统一套一个现成材质。

AI 提出了便携发电机、港口卷扬机和工业控制箱等候选，其中发电机比较适合同时练习喷漆金属、橡胶、塑料和贴花。不过今天仍然是选题讨论，尚未确认最终做哪个，也没有开始制作新的高低模。十天是用来约束项目范围的目标，不是已经确定的工期。

作品展示也提前列了需要保留的内容：最终画面之外，还应有高低模、线框、UV 布局、烘焙结果、材质贴图，以及面数和纹理规格。这样以后回看时，能知道画面是怎样做出来的，而不只剩一张成品截图。

## UV 练习素材与挤出笔记

为避免一边学建模、一边又被 UV 卡住，还提出先找一些现成模型，专门练展开。AI 查找了工具箱、灭火器和便携发电机等练习候选，思路是保留原模型和原 UV 作对照，在副本上重新展开。先从盒状结构开始，再到圆柱和管状零件，逐渐增加形状的复杂度。

这部分目前只完成了素材查找和练习安排，没有确认下载、重新展开或生成了新模型。后续练习时，原 UV 可以作为对照，但并不是只有一种展开方式才正确，仍然要看拉伸、切缝和实际纹理的使用效果。

学习延续到午夜，记下了墨化课程中两种挤出操作的区别：沿法向挤出时，选中的相邻面作为连续区域处理；各个面挤出则逐面独立处理，每个面形成自己的侧壁。

这里的“独立”不代表自动变成多个物体，它们仍可以属于同一个网格。区别主要在挤出后相邻面的连接方式。这个知识点先留作看课笔记，没有额外把它扩展成完成了一件新模型。

## 作品集方向

白天也讨论了技术美术和渲染方向是否还有新人入口。AI 协助查看了官方岗位，并区分了渲染 TA 与渲染程序的要求：两者有共同基础，但并不是同一条路线，也不能用某个团队的招聘情况代表整个行业。

这次讨论没有得出“做完几件作品就一定能进”的结论。当前更实际的事情仍是把已有渲染作品讲清楚，补齐资产流程，并逐渐积累个人实现、调试和验证的证据。课程可以帮助补基础，但最终需要用自己的工作说明会做什么、还不会什么。

今天的进展主要是把资产流程中的几个环节拆清楚，并为下一件练习控制范围。接下来先从简单模型体验 UV 展开，再决定完整 PBR 资产的题材；今天还没有把这些计划算作已经完成的成果。
