# 2026/10/15｜海湾场景搭建、UE MCP 与课程安排

## 海湾地形与资产试摆

今天开始按照参考图搭建海湾场景。想要的不是一片开阔海滩，而是被巨大崖壁包围的空间：两侧和远处的山体挡住大部分天空，镜头靠近水面，前方保留海湾和岸线的层次。

先处理了 Landscape 的范围，期间觉得地面太大，尝试去掉画面不需要的部分，后来又按原来的尺寸重新建了一块。随后开始找可以使用的资产，也询问了 Fab 上有没有接近参考的资源。下载后遇到只有材质和贴图、没有预期模型的情况，资源内容还需要继续确认。

晚上拿现有的悬崖资产自己摆了一轮。左侧已经有了比较大的岩壁体量，但检查时发现，几个名字不同的物体实际用了同一个网格，只是改变了摆放方式。相似的顶部轮廓反复出现，叠在一起后，复制感仍然比较明显。部分模型还与地形、相邻岩石穿插得过深，很多体积埋在地面里。

这一轮也开始把“模型放进场景”与“组合出合适的形状”分开看。同一块岩石可以重复使用，但只改位置和大小，不一定能得到自然的崖壁；还需要看整体轮廓、转折和与岸线的关系。当前阶段优先处理这些大形体，暂时不急着补小石头和装饰。

## MCP 连接与灰模调整

今天研究了 Unreal_mcp 项目的使用方式，并在 AI 协助下完成了 UE 5.6 插件的编译、安装和连接配置。过程中补装了 MSVC 与 Windows SDK，也区分了 Visual Studio 完整版和 Build Tools 的安装选项。插件加载时还遇到依赖模块没有启用的问题，补齐配置后，成功读取了当前关卡并截取视口。

连接之后，尝试让 AI 按参考图搭建灰模。前几轮结果没有贴合原有地形，也没有表现出参考里的空间关系，因此没有直接沿用，而是补发参考、重新调整。后续在现有 Landscape 上安排左右岩壁、后方峡壁、焦点岩和浅滩占位，并在当前视角创建了摄像机。

自己试摆资产后，又让 AI 先保存备份，再协助重新布置。调整重点是抬高两侧和远处的崖壁，减少天空面积，隐藏冲突的灰模墙体，并把摄像机降到更贴近水面的高度。

这一部分的插件配置、自动灰模搭建和最后一轮重排主要由 AI 完成；自己做的是地形操作、资源查找、资产试摆，以及对照参考提出修改。当前画面仍然处在搭建阶段，岩壁偏白、重复轮廓明显，岸线和中景也还需要整理，并不是已经完成的海湾场景。

## 图形学后续课程与作品集

上午讨论了 GAMES101 之后怎样继续深入。相比把推荐的课程全部按顺序学一遍，更倾向于先看 GAMES106，之后需要深入图形 API 和 Shader 实践时，再补 LearnOpenGL。GAMES202 暂时不打算整门学习，但考虑从中挑选一个作业，在理解原有实现后改编成图形技术展示项目。这些是后续安排，不是当天已经完成的课程内容。

今天也讨论了购买资源与作品集个人贡献的问题。现成的水体、材质和场景资产可以帮助完成视觉效果，但最后看起来相似的画面，背后可能是完全不同的工作：有人负责场景整合，有人实现 Shader，有人做性能分析和改进。作品说明需要把这些贡献分清楚，不能因为画面里出现了某个效果，就把整套技术都算作自己的实现。

结合这点，继续考虑视觉场景与图形技术实践怎样分配精力。场景需要构图、资产组合、灯光和整体完成度；技术项目则需要能够解释实现、展示对比和定位问题。今天还问到了地编是否包含灯光，进一步了解场景制作与岗位分工。现阶段仍先做小范围的场景实践，后续再逐步增加能够独立讲清楚的技术内容。
